# Agentic foundations & tool use

## Purpose
Understand the agent loop and identify where tools let an AI system act on a goal.

## Learning objectives
- Explain how an agent differs from a one-shot chatbot response.
- Break a task into a goal, steps, tool actions, and checks.
- Choose a low-risk task suitable for a first agent-assisted workflow.

## Lesson
An AI agent works toward a goal through a sequence of decisions and actions. A useful model is **plan → act → observe → adjust**. The model interprets a request, chooses a next step, calls a tool when needed, reads the result, and decides whether the goal is complete or another step is needed.

A tool is an action available through an app or service: searching a knowledge base, reading a calendar, editing a spreadsheet, or creating a draft. Tool use lets a system interact with its environment instead of only generating text. Each tool should have a clear purpose and permission boundary.

Agents can misunderstand goals, use incomplete information, or misread results. Make requests specific, expose only necessary tools, and add checks where errors would matter. Start with a repetitive task that is easy to review and reversible.

## Key takeaways
- A tool is an action an agent can take on your behalf.
- Work happens in steps, so you can check each one.
- Clear goals and limits produce better results than vague ones.

## Try it
Pick a task you repeat each week. Write its steps and apps. For each step, mark whether an agent could draft, retrieve, decide, or act. Identify one result you would review.

## Check your understanding
1. What makes an agentic workflow different from a single chatbot answer?
2. Name one check to add after an agent uses a tool.
