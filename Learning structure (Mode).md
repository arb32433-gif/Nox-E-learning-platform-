# Learning structure (Mode)

Different ways learning can be structured. Each mode shapes motivation, pacing, and how progress is measured.

## Classic
- **Module-Heavy**: Content is broken into discrete modules/chapters. You complete one module before unlocking the next. Clear prerequisites, predictable path, good for foundational knowledge.
- **Linear Progress**: A fixed sequence from beginner → advanced. No skipping ahead; mastery of step N is assumed before step N+1. Best when topics build on each other (math, language grammar).

## Challenge-led
- **Progress to Level Gauge**: Learners advance by completing challenges (quests, problems, projects) rather than consuming content. Progress is tracked by a level/gauge that fills as challenges are cleared. Emphasizes doing over watching; suits skill-based domains (coding, design, games).

## Choosing a mode
- Use **Module-Heavy / Linear** when the subject has a strict dependency chain and learners need scaffolding.
- Use **Challenge-led** when engagement and practice matter more than coverage, or when learners are self-directed.
- Hybrid: linear modules for theory, challenge gates for advancement.
